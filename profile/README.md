## Overview

PS3HEN (PlayStation 3 Homebrew Enabler) is a firmware modification environment developed by the PS3Xploit team. It enables homebrew execution and provides access to additional system-level functionality on compatible PlayStation 3 consoles.

The project supports multiple official and hybrid firmware configurations, offering payload execution, kernel plugin functionality, system patches, and integration with popular homebrew applications.

PS3HEN 3.6.0 expands multi-firmware support and introduces additional development features, plugin improvements, and updates to the integrated homebrew application resources.

## ⚡ Quick Start

1. **Check Firmware Compatibility** — Identify the PlayStation 3 model and installed firmware version. Verify compatibility with the official PS3HEN documentation.
2. **Prepare the Installation Environment** — Follow the PS3Xploit installation instructions for the corresponding OFW or HFW configuration.
3. **Install and Enable HEN** — Complete the installation procedure and activate PS3HEN through the console interface.

After activation, supported homebrew functionality and additional system tools become available through the PlayStation 3 interface.

## ❓ FAQ

**1. Does PS3HEN work on every PlayStation 3 model?**

PS3HEN supports a broad range of PlayStation 3 models, including systems that are not compatible with traditional CFW. Firmware compatibility must be checked before installation.

**2. What is the difference between PS3HEN and CFW?**

PS3HEN is a Homebrew Enabler that provides selected custom firmware-like capabilities through a different implementation. It is not a traditional full CFW installation.

**3. Does PS3HEN support Hybrid Firmware?**

Yes. PS3HEN supports compatible HFW releases, including HFW 4.93.1 CEX.

**4. Can PS3HEN run homebrew applications?**

Yes. It enables compatible homebrew applications and supports integration with tools such as Apollo Save Manager, IRISMAN, Movian, and other applications.

**5. How can PS3HEN be updated?**

Use the supported HEN update functionality or follow the installation and update instructions published in the official PS3Xploit repository.
